---
title: How it works
description: "Desk modes, optimize, measure, verify, restore."
---

Hertzline is a local desktop tool. It does not sync profiles to the cloud and does not invent cross-machine averages.

## Base modes

Open **Profiles**. Three built-in modes sit on top:

| Mode | Plugged in | On battery |
| --- | --- | --- |
| Study | Battery saver | Battery saver |
| Programming | Balanced | Battery saver |
| Performance | High performance | Balanced |

Hertzline reads AC vs battery and applies the matching OS power plan. It does **not** edit fan curves; quieter vs louder fans are an expected side effect of the plan.

## Optimize → Measure → Verify

1. **Optimize** — recommended Windows tips with Apply all (Game Mode, performance plan, Game Bar off).
2. **Measure** — local session metrics; missing sensors stay unavailable.
3. **Verify** — before/after only from your runs; helpful above the noise band.

## Per-game profiles

Separate from desk modes: action sets that apply when a game starts and restore on clean exit.

## What Hertzline does not do

- Fan curve editors or vendor overclock tools
- Registry "FPS boost" packs or Defender disable
- Injection or game file edits
- "+X FPS" marketing without your measurement
