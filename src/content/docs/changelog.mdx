## Status

**Not released yet.** There is no public desktop build, installer, or winget package available. Version numbers, download links, and checksums will appear here when the first signed artifacts exist.

Until then:

- Do not expect installers on a download page
- `winget install Hertzline.Hertzline` is reserved as the intended ID; it is not published until an approved manifest lands
- Site and docs work can ship ahead of the app (this repository)

## Format (when releases begin)

Each entry will list:

1. Version (`vMAJOR.MINOR.PATCH`)
2. Date
3. Highlights tied to measured features (no invented FPS gains)
4. Links to signed artifacts and SHA-256 checksums

Source of truth for product changelog text will live in the `app` repository and be mirrored here during release workflows.

## Website / docs notes

Scaffold and product pages for this site land before the first app tag. Those site-only milestones are tracked in the Hertzline workspace roadmap, not as user-facing app versions.
