title: How it works
description: "Hertzline flow: one-click recommendations, measure, verify before/after, restore if needed."
---

Hertzline is a local desktop tool. It does not sync profiles to the cloud and does not invent cross-machine averages. The loop is: optimize, measure, verify, restore.

## 1. Optimize (recommended pack)

Open **Ottimizza**. The three Windows recommendations sit on top:

1. Game Mode
2. High Performance power plan
3. Game Bar / capture off

**Applica tutte e 3** runs them in sequence. Every change shows state, risk, and how to undo. Elevation is requested per action only.

## 2. Measure a session

Pick a process or capture session. Hertzline records frame-time metrics when a supported source exists. Hardware, disk, and network fill in what the OS exposes. Missing values stay unavailable -- never invented.

## 3. Verify before/after

Benchmarks use a fixed duration, warm-up, and at least three measure passes. A change is helpful only if the gain beats the noise band on that machine. Below noise: "no measurable effect" and restore.

## 4. Profiles and Everyday

Documented launchers can detect games. Profiles can apply on launch and restore on clean exit. Everyday covers startup impact, resource reports, power presets, cleanup with preview, and thermal.

## What Hertzline does not do

- Registry "FPS boost" packs, Defender disable, unmeasured TCP "optimizers"
- Overclock / undervolt in v1
- Injection or game file edits
- Default telemetry or "+X FPS" claims without your measurement
