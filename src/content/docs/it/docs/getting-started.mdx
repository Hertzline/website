## Cosa fa Hertzline

1. **Misura** una sessione: frametime quando una sonda supportata e disponibile, piu collector hardware, disco e rete che il sistema espone.
2. **Modifica** solo le azioni che scegli. Ogni azione mostra cosa fa, effetto atteso, rischio e come annullare (AC-8.1).
3. **Verifica** con un benchmark before/after che riporta mediana e spread, e marca una modifica utile solo se il guadagno supera il rumore tra run (AC-2.x).
4. **Ripristina** ogni modifica in sospeso con Restore all in un clic, inclusi crash e disinstallazione (AC-7.x).

## Prima di installare

- Hertzline non inventa sensor mancanti. Le metriche non disponibili sono etichettate unavailable o not possible.
- L'app intera non gira elevata. L'elevazione e richiesta solo per azione.
- L'overlay resta spento di default se rileva marker anti-cheat (AC-6.2).
- Non ci sono claim di marketing "+X FPS". I guadagni arrivano solo dalle tue misure locali (AC-8.2).

## Everyday mode (AC-5.1--AC-5.6)

Fuori dai giochi, Everyday mode copre revisione impatto avvio, report resource hog senza kill silenziosi, preset di alimentazione, pulizia con anteprima, avvisi termici e riepilogo salute settimanale.

## Overlay opzionale (AC-6.1--AC-6.3)

Un overlay minimo FPS / frame-time usa solo metodi supportati, resta spento di default con marker anti-cheat e ha un controllo di disable globale.
