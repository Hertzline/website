## Does Hertzline guarantee more FPS?

No. Helpful only means your local before/after gain exceeded noise on that machine. Below noise you get "no measurable effect" and a revert offer.

## Will it fight anti-cheat?

Hertzline does not inject into games, read game memory, or modify game files. Overlay uses supported methods only and defaults off when anti-cheat markers are found. See [Anti-cheat](/anti-cheat/).

## Is there telemetry?

No telemetry by default. No ads, bundled software, mining, or data selling. Sessions stay on your machine unless you export a file.

## Why so few macOS toggles?

macOS exposes fewer public tunables. Hertzline documents that honestly (AC-4.23) instead of shipping fake options.

## Can I overclock with Hertzline?

Not in v1. Link out to official vendor tools for overclock, undervolt, fan, or power-limit changes.

## Where do downloads live?
