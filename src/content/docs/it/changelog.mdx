## Stato

**Non ancora rilasciato.** Non esiste ancora una build desktop pubblica, un installer o un pacchetto winget. Numeri di versione, link di download e checksum appariranno qui quando esisteranno i primi artifact firmati.

Fino ad allora:

- Non aspettarti installer sulla [pagina download](/it/download/) ancora
- `winget install Hertzline.Hertzline` e l'ID previsto; non e pubblicato finche un manifest approvato non arriva
- Sito e docs possono avanzare prima dell'app (questo repository)

## Formato (quando inizieranno le release)

Ogni voce elenchera:

1. Versione (`vMAJOR.MINOR.PATCH`)
2. Data
3. Evidenze legate a funzionalita misurate (niente guadagni FPS inventati)
4. Link ad artifact firmati e checksum SHA-256

La fonte di verita del changelog di prodotto vivra nel repository `app` e verra riflessa qui nei workflow di release.

Scaffold e pagine prodotto di questo sito arrivano prima del primo tag dell'app. Quei traguardi solo-sito sono tracciati nella roadmap del workspace Hertzline, non come versioni app rivolte agli utenti.
